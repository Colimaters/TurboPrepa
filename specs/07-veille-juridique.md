# 07 — Veille juridique

Dépend de : `00-architecture-generale-et-design.md`

## Objectif
Accès rapide, en un clic, aux sites de référence pour la veille juridique quotidienne.

## Fonctionnalités
- Liens directs (ouverture dans un nouvel onglet du navigateur) vers :
  - Le site du **Club des juristes**.
  - **Actu-Juridique**.
  - **Dalloz Actualité**.
  - **Légifrance**.
- Chaque lien présenté comme une carte cliquable avec le nom du site et une courte
  description de ce qu'on y trouve (ex. "Actualité doctrinale et jurisprudentielle").
- Les liens doivent être **modifiables** (l'utilisateur doit pouvoir changer une URL si un
  site change d'adresse, ou ajouter d'autres sites de veille de son choix).

## Critères d'acceptation
- [ ] Les 4 liens de base (Club des juristes, Actu-Juridique, Dalloz Actualité, Légifrance)
      sont présents et fonctionnels.
- [ ] Chaque lien s'ouvre dans un nouvel onglet, sans quitter l'application.
- [ ] L'utilisateur peut ajouter, modifier ou supprimer un lien de veille.
